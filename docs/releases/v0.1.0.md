# code-viz v0.1.0

Turn code, documentation and user journeys into interactive maps you can play, inspect and share.

The first release includes `flow-map`: layered components, scenarios, step playback,
drill-down views, source excerpts read from disk, and review findings attached to the map.
The builder uses native Node.js modules and produces a single offline HTML file.

## Try it

```sh
npx skills add benjoox/code-viz
```

Then ask your agent: “Map how this project's main workflow works.”
See the [README](https://github.com/benjoox/code-viz#readme) for Claude Code plugin installation,
manual installation and the bundled example.

## Requirements and limitations

Use Node.js 22 or 24. Refer to the repository's verification notes for tested installations
and environments. This is an early release; the schema and UI may evolve before 1.0.
Source excerpts are embedded in generated maps. Redaction is best-effort, so review before
sharing. The agent's interpretation of source is not guaranteed by the builder.

Report reproducible bugs using the issue template. Report vulnerabilities privately through
the Security tab. Feedback on real workflows will guide the next release.
