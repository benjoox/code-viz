# LinkedIn launch draft

I built code-viz to make a codebase easier to explain.

Ask your agent to map a workflow, then step through an interactive view of the components,
the files involved and the source excerpts behind each step.

The first skill, flow-map, is open source under MIT. It produces a single HTML page
with playback, drill-down and review findings attached to the map.

The video shows it in action. Try it on one workflow in your own project and tell me
where the explanation helps—or where it breaks down:
https://github.com/benjoox/code-viz

If you need a narrated explainer for your own developer tool, message me.

## Publishing checklist

- Publish after the launch PR, passing main-branch CI and v0.1.0 release.
- Preview both supplied video formats on a phone; choose the one with readable code and labels.
- Check captions against the narration, add an informative cover frame, and confirm audio levels.
- Upload the chosen video natively to LinkedIn and include the repository URL in the post.
- Confirm all footage and audio can be distributed publicly. The public demo must contain only public sample code.
- Record the post URL and feedback; use actual user reports to choose the next change.
