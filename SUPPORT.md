# Support

Search [existing issues](https://github.com/benjoox/code-viz/issues) before filing a bug or feature request.
Include your operating system, Node.js version, agent/version, command or prompt, and a
minimal sanitized example. Never upload a map of private code without checking its embedded data.

The project is maintained on a best-effort basis with no response-time commitment.
Use [private security reporting](SECURITY.md) for vulnerabilities and the
[code of conduct](CODE_OF_CONDUCT.md) for behavior concerns.

The Node.js builder is tested independently of agent installations. Agent names in the
installation instructions describe integration routes, not a guarantee of identical behavior.
See [verification notes](docs/verification.md) for what has actually been exercised.
